# MeetConnect

An Ethiopia-first social discovery MVP for consenting adults aged 18+.

This repository is being bootstrapped. The intended MVP includes a compact animated mobile UI, an 18+ age gate, gender-based discovery preferences, approximate meeting-area proposals, connection requests, reporting/blocking, and later Supabase and Chapa integration.

Important: authentication, persistence, moderation, location safeguards, and payments must be implemented and tested before production use.
